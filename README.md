An AI-powered web platform that analyzes patient symptoms, medical history, and health indicators to predict disease and classify patient risk (low / medium / high) — built as a decision-support tool for resource-constrained primary healthcare settings in Kenya.

## Overview

This system uses supervised Machine Learning models trained on structured patient data to support early disease detection for four conditions: diabetes, hypertension, heart disease, and respiratory illness. It is designed as clinical decision-support — not a replacement for professional diagnosis.
